CEYLON ODYSSEY TRAVELS
======================

Files: index.html, style.css, script.js

Run locally: Open this folder in VS Code. Use the Live Server extension or open index.html in a browser.

Before publishing, replace the sample phone number (+94 77 000 0000), email address, and generic social media links in index.html. Replace the WhatsApp URL in index.html with your business WhatsApp number in international format (digits only). Update any package descriptions, duration, imagery and business information to match the actual service.

The booking modal currently opens an email enquiry (mailto). It does not store bookings or process payments. A real booking system requires a backend or booking-service integration.

GitHub Pages: Upload the three website files to the repository root, then go to Settings > Pages > Deploy from a branch > main > /(root).

Images and Google Fonts are externally hosted. For a production launch, use properly licensed images and consider optimised, self-hosted assets. Test the layout and all links on mobile and desktop before publishing.
